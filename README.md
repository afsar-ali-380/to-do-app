# 📝 React To-Do App

This is a simple **To-Do App** built using **React** and **Vite**. The project is designed to demonstrate my ability to create modern React applications using hooks, manage state and props effectively, and utilize advanced features like the React Context API.

## 🔧 Technologies Used

- React (with functional components)
- Vite (for fast build and development)
- React Hooks (`useState`, `useEffect`, etc.)
- React Context API (for global state sharing)
- JavaScript (ES6+)

## 🧠 What I Learned & Showcased

- Creating a project using **Vite** and setting up a React environment.
- Using **hooks** to manage local component state.
- Passing and managing **state and props** between components.
- Implementing **React Context API** to share data across components.
- Building a clean and structured component-based UI.
